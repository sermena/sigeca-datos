SIGECA · Sistema Institucional de Gestión de Calidad

Guía maestra de documentos

Busque procedimientos, guías, manuales, formularios y normativa, y vea con qué otros documentos se relaciona cada uno.

Pruebe:
¿Cómo funciona este prototipo?
  1. Cada documento del SIGECA se registra una sola vez en una lista maestra (código, nombre, tipo, dependencia, proceso, versión, fechas, palabras clave y enlace al archivo oficial).
  2. Una segunda tabla registra las relaciones: qué normativa fundamenta cada procedimiento y qué guías, manuales, formularios u otros procedimientos utiliza.
  3. La lista se exporta a un archivo de datos (JSON) que esta página carga. La búsqueda ocurre en el navegador: no ignora tildes, tolera errores de digitación y pondera más el código y el nombre.
  4. El estado (vigente, próximo a vencer, revisión vencida) se calcula con la fecha de próxima revisión; el aviso se activa 90 días antes.
  5. Todo el código está acotado a un solo contenedor, por lo que puede insertarse como bloque o iframe en el sitio web institucional.

Los códigos, documentos y relaciones mostrados son ficticios y solo ilustran el funcionamiento.
